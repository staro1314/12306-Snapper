# Fast 12306

Fast 12306 是一个仅面向个人 Windows 本机的抢票辅助客户端。当前优先使用网页版调试，Vue 页面通过仅监听 `127.0.0.1` 的 Rust API 复用桌面版核心；验证通过后再打包 EXE。当前版本已实现当前 12306 登录、乘车人同步、余票查询、订单初始化/提交/排队/查单适配器和本地恢复闭环；2026-09-17 已由系统任务自动生成真实待支付订单完成闭环验收。真实提交默认可用，但每个任务必须由用户明确勾选授权。

## 当前可用能力

- Tauri 2 + Vue 3 桌面客户端；
- SQLite 本地任务持久化；
- 持久化 Chrome 官方登录窗口与登录状态检测；
- 基于当前官网 `/otn/passengers/query` 的只读乘车人同步，仅向页面返回不可逆引用、掩码姓名、票种和有效状态；
- 基于当前官网表单实际生成的 `/otn/leftTicket/queryG` 只读余票查询及候选车次/席别展示；
- 多任务、多日期、多路线组、多车次、多席别、多人优先级及可选截止时间；
- 在任务表单中直接查询当前官网车次并点选优先车次，每个路线组最多保留 5 个；同时保留手工输入以便调整顺序；
- 本地任务创建、表单回填编辑、删除和预检闭环；
- READY 前会对任务中的每个路线组执行当前官网只读兼容性探测；任一路线响应未知时停止进入自动执行；
- 自适应起售调度器：远离起售时低频等待、临近起售时 25ms 调度，按稳定优先级选择到期路线组，单批最多两个；
- 稳定候选排序、用户授权拆单及账号级全局提交锁；
- 提交前再次只读复查；拆单逐单串行，首单状态未知时绝不提交下一单；
- 当前官方页面的订单初始化、乘车人/席别选择、订单预检查、确认排队和排队结果识别；
- 提交超时或进程中断后强制进入 `UNKNOWN_RECONCILING`，先核对官方未支付订单；
- 订单快照、当前任务及冲突任务在同一个 SQLite 事务内保存；
- 调度误差、查询往返、候选决策、订单初始化和提交耗时持久化；
- 页面警报、系统通知、循环声音、标题闪烁、“我已查看并静音”和打开官方订单页；
- 与真实状态完全隔离的受控演练：有票拆单、无票、限流、超时先查单；
- 标记为 `SIMULATION` 的持久化执行日志和浏览器测试通知；
- 待支付、已支付、未知核对、限流和协议不兼容等独立状态；
- 真实订单快照独立存储和订单核对页面；测试演练不会写入真实订单视图；
- 当前协议配置：查询和真实提交链路已验证；真实提交必须同时满足任务级授权、Rust 协议门禁和浏览器执行器门禁。

## 安全边界

- 不自动支付，不处理候补；
- 不绕过滑块、短信或 App 核验；
- 超时或未知响应必须先核对官方订单，不能直接重提；
- 不保存完整证件号、Cookie、令牌或原始请求体到普通任务数据和日志；
- 真实提交默认可用，但只有明确勾选“允许真实自动下单”的任务才能执行；设置 `FAST_12306_ENABLE_REAL_SUBMISSION=0` 可作为紧急总开关关闭所有真实提交。

## 本地验证

```powershell
npm.cmd install
npm.cmd run dev:web
```

浏览器打开 `http://localhost:1420`。该命令同时启动网页、Rust API 和登录浏览器会话服务；不能只启动 Vite，否则登录按钮无法工作。开发数据存放在 `.local-data\fast-12306.db`，Chrome 会话存放在 `.browser-session\profile`，本地服务均不监听局域网地址。

构建及测试：

```powershell
npm.cmd run build
cargo test --manifest-path src-tauri\Cargo.toml
npm.cmd run tauri -- build --debug --no-bundle
```

无安装包构建产物位于 `src-tauri\target\debug\fast-12306.exe`。
